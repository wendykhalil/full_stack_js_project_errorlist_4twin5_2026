# Features Covered by the DevOps Evidence

This project includes backend/frontend logic and DevOps documentation around the following implemented modules:

- Email notification during account creation.
- Reset password and forgot password.
- Login with Face ID, WebAuthn/passkey Face ID, camera Face ID fallback.
- Login with Google.
- Register roles and direct login by email/role.
- Phone number login with SMS verification.
- Ollama/AI project creation support for artisans.
- Artisan CRUD.
- LibreTranslate API translation.
- Prescripteur display/features.
- Messaging documents, images, PDF, voice messages.
- Update/delete messages and archived messages.
- Real-time message notifications.
- Admin dashboards, analytics, fraud detection, activities/activity logs.
- Artisan dashboard statistics.
- Localization/map picker for project and profile.
- Devis, quotes and invoices CRUD.
- PDF/Excel export for quotes/invoices.
- AI generation in quotes and invoices.
- Pagination in artisan projects.
- Mouse-selected text explanation/description helper.
- Accessibility voice navigation and page reader/microphone controls.
- Profile page and Cloudinary image storage.
- ML prediction for project risk and delay.
- Smart analytics: demand forecasting, pricing trends, regional market insights.
